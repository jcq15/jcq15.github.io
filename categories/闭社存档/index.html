#蹲坑沉思

我发明一个指标，叫“吃价比”：

吃一种东西获得的快乐 ÷ 它带来的健康负担。

按这个标准，我觉得牛油果的吃价比很低。

它倒也不是难吃，只是没那么好吃，属于“有就吃、没有也完全不会想”的那种东西。但与此同时，它又是高脂肪、高热量食物。虽然主要是不饱和脂肪，脂肪质量不错，但这并不意味着把它额外加进饮食里就有什么明显健康收益。

牛油果真正比较合理的场景，是拿它替代黄油、蛋黄酱、肥肉之类更差的脂肪来源；如果本来不吃这些东西，只是因为“牛油果很健康”而特意多吃一个，那很多时候就只是多摄入了一堆热量。

所以我一直不太理解那种“其实也没多喜欢牛油果，但因为觉得它健康所以坚持吃”的行为。它又没有好吃到非吃不可，也没有健康到值得专门吃，为什么要吃？

很多所谓“超级食物”都有这个问题：营养学上的“成分还不错”，经过营销以后就变成了“吃它本身就是一种健康行为”。但食物不是游戏道具，吃个牛油果也不会给自己挂一个持续24小时的健康buff。

对我来说，既然健康收益并不特殊，那就应该回到最朴素的问题：好不好吃。不好吃的不吃，一般好吃但热量高的也没必要特意吃。

感觉网络流量已经完整经历过一轮很明显的“通货膨胀”。

刚能用手机上网的时候，流量还是按 KB 算的，后来慢慢变成 MB，再变成 GB。本科的时候校园网一个月有 20G 免费流量，当时感觉已经够用。现在再看，我光 VPN 一个月就能跑掉 100 多 GB，还没算那些不经过 VPN 的国内流量。

这种“通胀”其实不只是数据量变大这么简单。单位流量越来越便宜，网络基础设施越来越强，用户需求越来越高，默认质量标准也越来越高。以前 480p 算高画质，现在 1080p 都嫌糊；以前网页主要是文字和小图，现在短视频、直播、云同步、视频会议、游戏更新都在持续吃流量。

而且这些因素之间很难说谁是因谁是果，更像一张互相强化的网。

带宽变便宜了，开发者就没那么在意节省流量；软件和内容变得越来越重，又会推动用户去买更快的网络和更大的套餐。网络更快以后，产品又敢默认塞更高清的图片、更大的资源、更频繁的同步。用户逐渐习惯这些体验以后，又会把它们当成新的最低标准。

甚至连人的心理计量单位都会变。以前下载几十 MB 都会想一下要不要等 Wi-Fi，现在几个 GB 的更新很多时候连看都懒得看。现代人看到当年一个月30MB的流量套餐会觉得：这也叫流量？

我感觉 token 现在正在经历很像的过程，只不过还处在比较早期。

刚有 LLM 的时候，上下文只有几千 token，token 也贵，大家会认真压 prompt、截断历史、想办法少传一点东西。现在几十万、上百万 token 的上下文已经开始出现，API 计价单位也普遍变成了每百万 token。

接下来大概也会出现类似的循环：推理越来越便宜，上下文越来越长，开发者就越来越敢“挥霍” token；模型能吃更多上下文以后，用户又会开始习惯直接塞整份代码库、整本书、完整聊天记录；Agent 再进一步，把一次用户请求变成几十次甚至几百次模型调用。

最后需求会反过来继续推动更便宜的推理、更大的上下文和更高的吞吐。

所以现在看 100 万 token 还觉得是个很大的数字，但它可能只是当年的 20G 流量。

再过几年，说不定大家看到 100 万 token 的上下文，只会觉得：这也叫上下文？

如果地球上没有化石能源：一条平行世界的文明之路

在现实世界里，煤炭和石油是人类文明的巨大加速器。它们像几亿年前生物尸骸遗留下来的“时空宝藏”，支撑了工业革命、现代交通、化工产业乃至信息社会的建立。那么，如果历史上根本没有留下煤和石油，人类会走出一条怎样的科技发展之路？

本文尝试从地质、生态、技术路径和能源系统的角度，拼出一幅“无化石燃料的平行世界图景”。

为什么煤和石油能留下来

生物的遗体通常会被细菌和真菌分解成二氧化碳和水，为什么部分植物和浮游生物的尸体却能保存为煤和石油？答案是缺氧环境。

  • 煤炭：源自古代沼泽森林的植物残体。在缺氧积水的环境里，分解者“无力工作”，遗骸被泥沙埋藏，经数千万年的高温高压转化为煤。
  • 石油：源自远古海洋的浮游生物与藻类。在海底淤泥缺氧的条件下被封存，地质压力将其慢慢裂解成液态烃类。
  • 类比泥炭鞣尸：在法医学中，泥炭沼泽能保存古代尸体，原理与煤炭形成类似——缺氧环境抑制了腐败过程。

换句话说，煤炭和石油就是“分解失败的遗物”。

为什么生物没“赢麻”去分解煤石油

既然它们是有机物，为什么分解者不把它们当大餐？

  1. 化学结构稳定：煤几乎接近碳化，石油主要是稳定的碳氢链，缺乏可攻击的化学键。
  2. 可利用性差：煤不溶于水，石油难以进入代谢通道。
  3. 进化时机：煤石油大多深埋地下，生物无法接触，自然选择不会推动分解酶的演化。
  4. 也不是没人能吃：一些细菌能慢慢降解石油（石油泄漏现场的“清道夫”），真菌和细菌也能微弱地啃煤，但效率极低。
  5. 投资回报率低：相比易得的糖和蛋白质，煤石油像是“保险柜里的硬骨头”，分解代价大，回报慢。

  • 人口增长受限，因缺乏廉价化肥。

  • 能源瓶颈更早显现，核裂变一旦发现，可能优先用于发电，而不是先作为武器。
信息革命的延迟
  • 半导体工业依赖石化材料，电子工业会比现实晚。
  • 但电气化社会更早，电报与机械计算机可能更繁荣。
技术发展顺序对比
  • 现实世界：煤炭 → 蒸汽机 → 石油 → 汽车/塑料 → 电气化 → 信息革命
  • 平行世界：水/风 → 电气化（提前） → 电轨交通 → 生物基材料 → 核能（提前） → 信息革命（延迟）

换句话说，能源与交通走在前头，材料和信息落在后头。

只靠水电+风电，够不够？
  • 当前全球用电量约 29,500 TWh/年。
  • **水电+风电（2023）**合计约 6,600 TWh，仅占 ~22%。
  • 技术潜力：水电上限 ~14,600 TWh，风电潜力 19,000–125,000 TWh，理论上可以覆盖全面电气化后的需求（~100,000 TWh），但要依赖超级电网、储能和跨洲互联。

换句话说，“只靠水风”在物理潜力上勉强够，但现实执行上难度极高，社会需要付出比现实更巨大的基础设施代价。

哲学意味

如果没有煤和石油，人类文明可能会更慢，但也更“干净”：

  • 没有雾都伦敦，没有石油战争。
  • 全球变暖问题可能不至于爆发。
  • 城市紧凑，公共交通主导，世界格局围绕水资源和铀矿展开。

化石能源在现实中是加速器，但同时也是陷阱。它让人类几百年内快速跨越了技术门槛，也让我们陷入了气候危机。

结语

煤和石油是“分解失败的遗物”，它们塑造了我们熟知的现代世界。如果没有它们，人类依然能点亮科技树，只是顺序和代价完全不同。能源、电力、核能会走在前面，而塑料、化肥、信息化会姗姗来迟。

在那条平行世界里，人类或许还没登月，但地球气候也没有被碳排放推向危险的临界点。
