# 今日怪诗

2021.03.29 05:53 片刻

#今日怪诗
我总是理所当然的忘了一些人
就像生活总是理所当然的忘了我
各个楼层都是撤硕
每个坑里我都留下一坨
那个坑里的奥利给
太干了，只留下坚硬的壳
路人不小心踩到的
是食物的灵魂在漂泊
而给你的纸
被我擦鼻涕用了
你就蹲着吧
蹲到腿麻也没人救你
像极了生活

（灵感来自图，图来自网络）
